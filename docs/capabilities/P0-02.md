## Evidence Rules

- `supported` is not inferred from a schema, design example, package being enabled in configuration, or a fake response.
- `unverified` means source/configuration evidence exists but live behavior has not been authorized or exercised. Runtime-loaded state remains separate from static enabled configuration.
- `unsupported` is scoped to the inspected `napcat-plugin-cleaner` adapter surface. It does not assert that no other adapter could implement the action.
- Each action row in `tests/contract/capabilities/napcat-plugin-cleaner.matrix.json` records input/output schema, pagination/cursor, effects, reference/read-back, timeout/error distinctions, retry, writer surface, adapter versions, and source evidence IDs.
- Unknown is fail-closed. An ambiguous write timeout remains unknown and is never replayed automatically.
